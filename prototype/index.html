AODA & WCAG 2.0/2.2 Quick Guide

Under Ontario's Accessibility for Ontarians with Disabilities Act (AODA), public websites and web apps must meet WCAG 2.0 Level AA (with WCAG 2.2 as the modern best-practice standard) based on four core principles—POUR:

  • Perceivable: Provide text alternatives (alt) for images, captions, and sufficient colour contrast.
  • Operable: Ensure all interactive controls work via keyboard navigation with clear focus states.
  • Understandable: Set page language (lang), pair inputs with <label>, and provide clear error messages.
  • Robust: Use valid semantic HTML and accessible names (aria-label, title) for buttons, links, and iframes.
